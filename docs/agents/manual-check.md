# 実機の手動確認（エージェント向け）

`docs/manual-checks.md` の項目を実機で確かめるときの決まり。操作は `tools/win-driver` を通す（組み方と呼び方は [windows-dev.md](windows-dev.md) の「実機を道具で操作する」、コマンドの一覧は `scripts/win-driver.sh --help`）。

## 安全の決まり

同じ PC でユーザーの shunsoku が常駐し、ほかのエージェントも確かめていることがある。次は道具の中に持っていて、破ると道具が終了コード 3 で止める。道具を通さずに同じことをしない。

- 起動: `launch` / `run` で起動できるのは `shunsoku.exe` と `shunsoku-cli.exe` だけ（ほかの exe は断る）。入力の宛先にしてよいのは、起動した `shunsoku.exe` のウィンドウだけ。`shunsoku-cli.exe` は止められるが、入力の宛先にはならない。起動には必ずテスト用の環境を付ける。`APPDATA`（設定とログ）と `TEMP` / `TMP` は `DRV_ROOT` の下、`USERNAME`（多重起動の判定の名前）と `SHUNSOKU_AUTOSTART_VALUE`（Run キーの値の名前）は `shunsoku-test-<DRV_ROOT のフォルダ名>`。ポータブルモードの項目（`--portable`）だけ `APPDATA` を付けない。
- 入力: キー・文字・マウス・クリップボードの前に、毎回前面のウィンドウが自分の起動した本体のものか確かめる。マウスは、カーソルを動かす前に、動かす先（ドラッグは通る点すべて）の下のウィンドウも確かめる。動かした後にもう一度確かめ、違えばカーソルを元に戻して送らない。ターミナルが前面のままなら、先に `activate <hwnd>` で前面にする。
- 例外のホットキー（`hotkey`）: 登録されていない組み合わせは前面のウィンドウに届くので、前面が自分の起動した本体か、デスクトップかタスクバー（`Progman` / `WorkerW` / `Shell_TrayWnd` / `Shell_SecondaryTrayWnd`）のときだけ送る。どちらでもなければタスクバーを前面にしてから確かめ直し、それでも違えば送らない。自分の起動した本体が動いていなければ送らない。テスト用の本体のホットキーは、ユーザーの常駐する shunsoku と違う組み合わせにしておく（同じだと、ユーザーの shunsoku が受け取る）。
- 例外のトレイのクリック（`tray-click <pid>`）: 自分の起動した本体のアイコンの矩形（`Shell_NotifyIconGetRect`）の中心だけをクリックする。矩形が空か、その点の下が通知領域でなければ、カーソルを動かす前に断る。動かした後にも確かめ、違えば戻す。アイコンがあふれた側（`^` の中）に隠れていると矩形が取れない（Windows 11 では新しい exe のアイコンは隠れる）。そのときはクリックせず、シェルが送るのと同じ `NIN_SELECT` を本体に送り、`posted NIN_SELECT` と出す（シェルからの届き方は確かめていないので、結果にそう書く）。アイコンを出す設定はユーザーの環境なので変えない。メニューを開くだけなら `tray-menu <pid>`（クリックせず、本体にメッセージを送る。隠れていればカーソルの位置に開く）。
- 停止: `kill` は自分が起動した PID（`<DRV_ROOT>\launched.txt` に起動時刻と一緒に控える）だけを止める。`taskkill /IM` や PID の指定で、道具の外から止めない。
- 待つ: 固定の `sleep` ではなく `wait-*` で待つ。時間切れ（既定 5 秒、`--timeout ms`）は終了コード 1。時間切れを「動かない」と判定する前に、待つ条件が合っているか（ログの文言、ウィンドウのクラス）を確かめる。
- 片付け: 終わったら `pids` が空になるまで `kill` し、`DRV_ROOT` のフォルダを消す。ユーザーの `%APPDATA%\shunsoku` は読むだけにする（ポータブルモードの項目では、前後の大きさと更新時刻を控えて比べる）。

## 判定の仕方

`docs/manual-checks.md` の「判定」の列に従う。

- 値: 道具で読んだ値で判定する。画像は撮らない。
  - コントロールの文字・状態: `kids <hwnd>`（ID、クラス、文字、位置、有効か、チェック、選択、ホットキー）、`text <hwnd>`、`fg`（前面とフォーカス）。
  - メニュー: `tray-menu <pid>` か右クリックで開いてから `menus`。
  - タブ: `tabs <hwnd>`。一覧: `listview <hwnd>`（文字が切れていれば `CLIPPED` を出して終了コード 1）。
  - ファイルとログ: `now` で時刻を控えてから `wait-file <path> --since <時刻>`、`lines <file>` で行数を控えてから `wait-log <file> <部分> --skip <行数>`。
- 目視: 画像を見ないと判定できないものだけを `scripts/win-screenshot.sh` で撮って見る。目視の項目でも、値で決まる部分（例: M5-10 の、一覧の文字が切れないこと）は値で確かめる。
- 人: エージェントは確かめない。結果に「人」と書いて残す。
- 自動・自動（実機）: 手では通さない。「自動（実機）」は `cargo.exe test --workspace -- --ignored` の結果を書く（windows-dev.md の「実機でだけ走らせるテスト」）。
